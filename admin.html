Admin Task Solution

Halaman pribadi untuk menambah portofolio, proof, dan testimoni. Jangan bagikan link halaman ini dan token-mu.

1. Sambungkan ke GitHub
Cara membuat token (sekali saja)
  1. Buka GitHub, klik foto profil, lalu Settings.
  2. Paling bawah menu kiri: Developer settings, lalu Personal access tokens, lalu Fine-grained tokens.
  3. Klik Generate new token. Nama bebas, misalnya admin web. Pilih masa berlaku terpanjang.
  4. Repository access: pilih Only select repositories, lalu pilih Tasksolution.
  5. Permissions, lalu Repository permissions, cari Contents dan ubah menjadi Read and write.
  6. Klik Generate token, salin tulisan yang diawali github_pat_, lalu tempel di kolom di atas.
